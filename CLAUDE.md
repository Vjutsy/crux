# Crux — правила проєкту для Claude

Казуальна мобільна веб-гра (PWA) про скелелазіння для вивчення **словацької** (інтерфейс українською).
Не складна гра «для корисного вбивства часу». Замовник погодив рішення в `docs/decisions.md` — не змінюй механіку без погодження.

## Команди

- `npm run dev` — dev-сервер (відкривається з телефона в тій самій мережі через `--host`)
- `npm run check` — typecheck + eslint + prettier + vitest (запускай перед кожним комітом)
- `npm run build` — продакшн-збірка в `dist/` (base `/crux/` для GitHub Pages)
- `SEEDS=1000 npm test -- generator` — повна перевірка проходимості стін (довго)
- `npm run e2e` — Playwright: проходження стіни на мобільному в'юпорті (локально: `CHROME_PATH=/usr/bin/google-chrome`)

## Архітектура

- `src/core/` — чиста логіка без Phaser, покрита тестами:
  - `body.ts` — скелет (4 кінцівки), розв'язувач пози, IK. Досяжність = чи існує валідна поза тулуба.
  - `generator.ts` — стіна з seed + `findRoute` (пошук по позах) + бонусні зачепи на маршруті. Генератор гарантує проходимість.
  - `climb.ts` — правила проходження: кроки, бонусні зачепи, комбо, зісковзування, програш.
  - `questions.ts` — питання з групи слів, дистрактори, коробки Лейтнера.
  - `answer.ts` — перевірка вписаного (діакритика, 1 одрук для слів ≥ 6 літер).
  - `save.ts` — прогрес в IndexedDB, серія днів.
- `src/scenes/ClimbScene.ts` — рендер стіни й тіла (Phaser 4), ввід, камера, втома, навчання на 1-й стіні.
  - `ragdoll.ts` — падіння: тіло з поточної пози → регдол на Matter.js; малюється тією ж SVG-моделлю, повернутою за хребтом.
  - `backgrounds.ts` — процедурні фони під тему (плитка, шпалери, цегла, небо).
- `src/audio.ts` — синтезовані звуки й тиха музика (Web Audio, без файлів).
- `src/ui/climberArt.ts` — SVG-модель скелелаза (вид ззаду, казковий книжковий стиль) на тому ж скелеті; шар `#actor` поверх canvas з viewBox = видима частина світу.
- `src/data/climbers.ts` — 3 скелелази: Іва, Мартин, Бо (лише зовнішність: шапка, светр, шарф, коса).
- `src/ui/` — DOM-оверлеї: картка питання, меню, результат, тости.
- `src/content/sk/*.json` — групи слів (тема × рівень), схема Zod у `content/schema.ts`.
- `src/data/walls.json` — параметри 10 стін.

## Правила гри (погоджено)

- **Без таймерів.** Програш лише: скінчились кроки / немає опори / немає досяжних зачепів.
- Кожен рух кінцівкою коштує 1 крок. На звичайних зачепах **питань немає**.
- **Сині зачепи — лише бонусні** (генератор ставить їх на маршрут кожні 3–5 рухів). Тап по синьому → питання:
  правильно — +3 кроки; неправильно — скелелаз усе одно перелазить, бонус згорає, картка відлітає.
- Кожна 3-тя правильна відповідь поспіль — ще +1 крок (комбо); помилка скидає комбо.
- Кроки на старті = `stepFactor` × довжина еталонного маршруту (`walls.json`): без правильних відповідей до вершини не дійти.
- Втома = частка витрачених стартових кроків → тремтіння тіла, серцебиття, тряска; при помилці може зісковзнути нога.
- Кожна кінцівка окремо; тап по зачепу без вибору — гра підбирає кінцівку. Досяжні звичайні зачепи — залиті кольором теми.
- Картка: 4 кольорові варіанти a/b/c/d (помаранчевий, синій, зелений, червоний) або вписування.

## Конвенції

- TypeScript strict, без `any`. Коментарі й тексти UI — українською.
- Зміни в `core/` — лише з тестами. Детермінізм: усе випадкове — через `mulberry32(seed)`.
- Нові слова: перевіряти написання й рід у словниках SAV (slovnik.juls.savba.sk). Розмовні форми — лише в `skAlt`, основна форма нормативна. Стан перевірки — у `docs/content.md`.
- `?debug` у URL відкриває `window.crux` (Phaser.Game) для e2e і налагодження.
