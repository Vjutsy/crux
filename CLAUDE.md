# Crux — правила проєкту для Claude

Казуальна мобільна веб-гра (PWA) про скелелазіння для вивчення **словацької** (інтерфейс українською).
Не складна гра «для корисного вбивства часу». Замовник погодив рішення в `docs/decisions.md` — не змінюй механіку без погодження.

## Команди

- `npm run dev` — dev-сервер (відкривається з телефона в тій самій мережі через `--host`)
- `npm run check` — typecheck + eslint + prettier + vitest (запускай перед кожним комітом)
- `npm run build` — продакшн-збірка в `dist/` (base `/crux/` для GitHub Pages)
- `SEEDS=1000 npm test -- generator` — повна перевірка проходимості стін (довго)
- `npm run e2e` — Playwright: проходження стіни на мобільному в'юпорті (локально: `CHROME_PATH=/usr/bin/google-chrome`)

## Архітектура

- `src/core/` — чиста логіка без Phaser, покрита тестами:
  - `body.ts` — скелет (4 кінцівки), розв'язувач пози, IK. Досяжність = чи існує валідна поза тулуба.
  - `generator.ts` — стіна з seed + `findRoute` (пошук по позах) + бонусні зачепи на маршруті. Генератор гарантує проходимість.
  - `climb.ts` — правила проходження: кроки, бонусні зачепи, комбо, зісковзування, програш.
  - `questions.ts` — питання з групи слів, дистрактори, коробки Лейтнера.
  - `answer.ts` — перевірка вписаного (діакритика, 1 одрук для слів ≥ 6 літер).
  - `save.ts` — прогрес в IndexedDB, серія днів.
- `src/scenes/ClimbScene.ts` — рендер стіни й тіла (Phaser 4), ввід, камера, втома, навчання на 1-й стіні.
  - `ragdoll.ts` — падіння: тіло з поточної пози → регдол на Matter.js; малюється тією ж SVG-моделлю, повернутою за хребтом.
  - `backgrounds.ts` — стіни й зачепи за дизайном «Скеледроми і зачепи»: декор під тему, зачепи-предмети теми, теми kuchyna/dom/mesto/cas/auto, у змішаному режимі оформлення чергується по стінах (`MIX_ORDER`); стани (далекий, досяжний з ореолом, під кінцівкою, підказка, синій самоцвіт «+3», згорілий бонус, вершина з прапорцем). SVG-шар `#scenery` під скелелазом, пульсація — SMIL.
- `src/audio.ts` — синтезовані звуки й тиха музика (Web Audio, без файлів).
- `src/ui/climberArt.ts` — SVG-модель скелелаза (вид ззаду, казковий книжковий стиль) на тому ж скелеті; шар `#actor` поверх canvas з viewBox = видима частина світу.
- `src/data/climbers.ts` — 3 скелелази: Іва, Мартин, Бо (лише зовнішність: шапка, светр, шарф, коса).
- `src/data/skins.ts` — 8 скінів (свої в кожного скелелаза), відкриваються за загальні зірки (`need`); вибір — `settings.skins`, вигляд — `lookOf`. Убори й деталі на спині — `fancyCap`/`backExtras` у `climberArt.ts`.
- `src/ui/` — DOM-оверлеї: картка питання, тости; `screens.ts` — вступ при першому відкритті (3 картки → стіна 1 з підказками), головне меню «Казкові сутінки» (тап по скелелазу — вибір, іконка звуку — панель), «Куди лізти?», результат. Шрифти Neucha + Nunito з `@fontsource` (офлайн).
- Phaser-canvas прозорий: він дає камеру, ввід і фізику регдолу, а все видиме — SVG-шари `#scenery` і `#actor` із viewBox = видима частина світу.
- `src/content/sk/*.json` — групи слів: 5 тем (kuchyna, dom, mesto, cas, auto) × A1, A2, B1, B2, по 100 слів (A0 немає); `content/index.ts` додає змішані групи `mix-*` («Усе вперемішку»: кожен рівень і `ALL`), схема Zod у `content/schema.ts`. Слова випадкові й щоразу різні: `pickWord` бере випадкове з ще не показаних, потім з найдавнішої третини, слова з помилкою повертає частіше; rng питань — з `randomSeed()` на кожну спробу (стіна — з seed); журнал `seen` + лічильник `asked` у прогресі.
- `src/data/walls.json` — параметри 10 стін.

## Правила гри (погоджено)

- **Без таймерів.** Програш лише: скінчились кроки / немає опори / немає досяжних зачепів.
- Кожен рух кінцівкою коштує 1 крок. На звичайних зачепах **питань немає**.
- **Сині зачепи — лише бонусні** (генератор ставить їх на маршрут кожні 2–3 рухи, `BONUS_EVERY`). Тап по синьому → питання:
  правильно — +3 кроки; неправильно — скелелаз усе одно перелазить, бонус згорає, картка відлітає.
- Кожна 3-тя правильна відповідь поспіль — ще +1 крок (комбо); помилка скидає комбо.
- Кроки на старті = `stepFactor` × довжина еталонного маршруту (`walls.json`): без правильних відповідей до вершини не дійти.
- Падіння: регдол гепається на підлогу, над головою кружляють мультяшні зірочки (`dizzy.ts`), потім — екран результату.
- Втома = частка витрачених стартових кроків → тремтіння тіла, серцебиття, тряска; при помилці може зісковзнути нога: з'їжджає на нижчий зачіп і забирає `SLIP_COST` = 2 кроки (20.11, чекає підтвердження).
- Кожна кінцівка окремо. Кисть чи стопу можна тягнути пальцем до зачепа: вона «прилипає» до досяжного зачепа в радіусі `SNAP`, і той збільшується. Тап по зачепу теж працює — гра підбирає кінцівку. Досяжні зачепи світяться теплим ореолом.
- Над стіною є «небо» (`SKY` у ClimbScene): камера піднімається вище стіни, щоб верхні зачепи не ховались під HUD.
- Картка: 4 кольорові варіанти a/b/c/d (помаранчевий, синій, зелений, червоний) або вписування — системною клавіатурою (ігрової немає); назви кінцівки на картці немає.
- Результат — «Листівка» (`showResult` у `screens.ts`, дизайн F): анімація ~1.1 с, звуки `pik`/`star`/`chord`.

## Робочий процес

- Почни з `docs/handoff.md` — там стан, відкриті питання й наступні кроки.
- Кожну зміну — одразу в коміт з описом українською і пуш у `main` (CI сам задеплоїть); перевір, що CI зелений.
- Нове рішення замовника → `docs/decisions.md`; наприкінці роботи оновлюй «Стан», «Що далі» й «Історію» в `docs/handoff.md`.

## Конвенції

- TypeScript strict, без `any`. Коментарі й тексти UI — українською.
- Зміни в `core/` — лише з тестами. Детермінізм: усе випадкове — через `mulberry32(seed)`.
- Нові слова: перевіряти написання й рід у словниках SAV (slovnik.juls.savba.sk). Розмовні форми — лише в `skAlt`, основна форма нормативна. Стан перевірки — у `docs/content.md`.
- `?debug` у URL відкриває `window.crux` (Phaser.Game) для e2e і налагодження.
