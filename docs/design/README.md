## Візуальна мова

- Настрій: тиха казка-сутінки, як ілюстрована дитяча книжка; мало слів, багато повітря.
- Кольори: індиго-папір `#1c1a2b` / `#24223a`, крейдяний кремовий `#ece3d0`, приглушений `#b4abc2`, теплий ліхтар `#f0b96a`, чорнило контуру `#221c2c`.
- Шрифти: Neucha (заголовки), Nunito (текст), офлайн через `@fontsource`.
- Скелелаз — вид ззаду, скелет як у фізиці (тулуб 40, рука 66, нога 72, плечі ±11, таз ±9), кінцівки-«капсули» з чорнильним контуром.
- Теми стін: kuchyna (плитка, полиця, вікно), dom (шпалери, рамки, бра), mesto (цегла, ліхтар, афіша з трамваєм), cas (скеля, нічне небо, хмари, місяць).
- Зачепи: форма — від теми (3 на тему), стан — світлом: далекий тьмяний, досяжний з теплим ореолом, під кінцівкою з крихтами магнезії, підказка з пунктирним кільцем, бонус — синій самоцвіт з біркою «+3», згорілий — сірий тріснутий з димком, вершина — прапорець.
- Картка питання: 4 варіанти кольорами a/b/c/d — помаранчевий, синій, зелений, червоний.
