# Crux — з чого почати в новому чаті

Оновлено: 20.11.2026. Цей файл — точка входу: прочитай його, потім [CLAUDE.md](../CLAUDE.md) і [decisions.md](decisions.md), і можна працювати далі.

## Що це

Казуальна мобільна веб-гра (PWA) про скелелазіння для вивчення **словацької**, інтерфейс українською.
Робиться на замовлення; замовник погоджує механіку — без погодження правила гри не міняємо.

- Гра: https://vjutsy.github.io/crux/
- Репозиторій: https://github.com/Vjutsy/crux (публічний, гілка `main`; кожен пуш → CI → деплой на GitHub Pages)
- Погоджені рішення: [docs/decisions.md](decisions.md)
- Стан перевірки слів: [docs/content.md](content.md)
- План розробки (копія артефакту): [docs/design/plan.html](design/plan.html) — відкрити в браузері
- Дизайни: [docs/design/README.md](design/README.md)

## Як продовжити в іншому чаті

1. Підключи до чату репозиторій **Vjutsy/crux** (з правом на запис).
2. Напиши, наприклад: «Продовжуємо Crux. Прочитай docs/handoff.md і CLAUDE.md, далі — …».
3. Після кожної зміни: `npm run check`, коміт з описом українською, пуш у `main`, перевірити, що CI зелений.
   Наприкінці роботи — оновити цей файл (розділи «Стан» і «Що далі»).

Локально: `npm install`, `npm run dev`, `npm run check`, `CHROME_PATH=/usr/bin/google-chrome npm run e2e`.
Перед e2e зупини старий `vite preview` (`pkill -f "vite preview"`), інакше Playwright підхопить збірку з іншим base.

## Стан (20.11.2026)

Готово й задеплоєно:

- 10 згенерованих стін, кожна прохідна (генератор шукає маршрут по позах тіла); 4 теми × A0–A2, 345 слів.
- Тіло з 4 кінцівок з IK: нога не стане туди, куди фізично не дістає. Кожна кінцівка окремо.
- Керування: тягнути кисть/стопу пальцем до зачепа (прилипає, зачіп збільшується) або тапнути по зачепу.
- Кроки: рух −1; питання лише на синіх бонусних самоцвітах (кожні 3–5 рухів): правильно +3, неправильно — бонус згорає; кожна 3-тя правильна поспіль +1.
- Без таймерів. Втома від витрачених кроків: тремтіння, серцебиття, тряска, може зісковзнути нога.
- Падіння: регдол гепається на підлогу, над головою кружляють мультяшні зірочки, потім — результат.
- Меню «Казкові сутінки»: головний (Грати, звук, тап по скелелазу — вибір Іва/Мартин/Бо, серія днів) → «Куди лізти?» (тема, A0–A2, стіна 1–10) → «Лізти!».
- Вступ при першому відкритті (3 картки) → стіна 1 з підказками.
- Стіни й зачепи-предмети під тему, «небо» над стіною, синтезовані звуки й тиха музика.
- PWA офлайн; нова версія сама підміняє стару й перезавантажує сторінку (з 18.11).
- Тести: 68 юніт (vitest), 5 e2e (Playwright, мобільний в'юпорт), CI: check → e2e → deploy.

## Відкриті питання до замовника

- **Баланс стіни 1 «Кухня і їжа»:** до вершини можна дійти без жодної правильної відповіді (стартових кроків 18, а найкоротший шлях коротший за еталонний маршрут 20). Пропозиція: рахувати стартові кроки від найкоротшого шляху. Чекає відповіді.
- 2 чи 3 скелелази (зараз 3).
- Чи дозволяти дві руки на одному зачепі (зараз дозволено).
- Хто звіряє 345 слів: словник SAV (slovnik.juls.savba.sk) і/або носій мови.
