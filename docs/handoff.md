# Crux — з чого почати в новому чаті

Оновлено: 22.11.2026. Цей файл — точка входу: прочитай його, потім [CLAUDE.md](../CLAUDE.md) і [decisions.md](decisions.md), і можна працювати далі.

## Що це

Казуальна мобільна веб-гра (PWA) про скелелазіння для вивчення **словацької**, інтерфейс українською.
Робиться на замовлення; замовник погоджує механіку — без погодження правила гри не міняємо.

- Гра: https://vjutsy.github.io/crux/
- Репозиторій: https://github.com/Vjutsy/crux (публічний, гілка `main`; кожен пуш → CI → деплой на GitHub Pages)
- Погоджені рішення: [docs/decisions.md](decisions.md)
- Стан перевірки слів: [docs/content.md](content.md)
- План розробки (копія артефакту): [docs/design/plan.html](design/plan.html) — відкрити в браузері
- Дизайни: [docs/design/README.md](design/README.md)

## Як продовжити в іншому чаті

1. Підключи до чату репозиторій **Vjutsy/crux** (з правом на запис).
2. Напиши, наприклад: «Продовжуємо Crux. Прочитай docs/handoff.md і CLAUDE.md, далі — …».
3. Після кожної зміни: `npm run check`, коміт з описом українською, пуш у `main`, перевірити, що CI зелений.
   Наприкінці роботи — оновити цей файл (розділи «Стан» і «Що далі»).

Локально: `npm install`, `npm run dev`, `npm run check`, `CHROME_PATH=/usr/bin/google-chrome npm run e2e`.
Перед e2e зупини старий `vite preview` (`pkill -f "vite preview"`), інакше Playwright підхопить збірку з іншим base.

## Стан (20.11.2026)

Готово й задеплоєно:

- 10 згенерованих стін (12→26 рухів у генераторі), кожна прохідна; 5 тем × A1–B2 по 100 слів (2000) + «Усе вперемішку»; слова чергуються між стінами.
- Тіло з 4 кінцівок з IK: нога не стане туди, куди фізично не дістає. Кожна кінцівка окремо.
- Керування: тягнути кисть/стопу пальцем до зачепа (прилипає, зачіп збільшується) або тапнути по зачепу.
- Кроки: рух −1; питання лише на синіх бонусних самоцвітах (кожні 2–3 рухи): правильно +3, неправильно — бонус згорає; кожна 3-тя правильна поспіль +1. Старт 0.62→0.40 маршруту.
- Без таймерів. Втома від витрачених кроків: тремтіння, серцебиття, тряска, може зісковзнути нога.
- Зісковзування ноги від утоми: нога з'їжджає вниз і забирає 2 кроки (треба підтвердити).
- Скіни: 8 (по 3/3/2 у Іви, Мартина, Бо), відкриваються за зірки 3…60; вибір у панелі скелелаза («Вбрання»), «Новий скін!» на листівці.
- Вершина: руки на краю стіни, потім листівка.
- Результат — «Листівка» (дизайн F з полотна «Crux — варіанти меню»), з анімацією й звуками.
- Картка питання без назви кінцівки; вписування — системною клавіатурою.
- Тема «Авто й водійські права»: бетонна стіна паркінгу, зачепи — шини, кермо, конуси.
- Падіння: регдол гепається на підлогу, над головою кружляють мультяшні зірочки, потім — результат.
- Меню «Казкові сутінки»: головний (Грати, звук, тап по скелелазу — вибір Іва/Мартин/Бо, серія днів) → «Куди лізти?» (тема, A1–B2 або «Усі» у змішаному, стіна 1–10) → «Лізти!».
- Вступ при першому відкритті (3 картки) → стіна 1 з підказками.
- Стіни й зачепи-предмети під тему, «небо» над стіною, синтезовані звуки й тиха музика.
- PWA офлайн; нова версія сама підміняє стару й перезавантажує сторінку (з 18.11).
- Тести: 103 юніт (vitest), 8 e2e (Playwright, мобільний в'юпорт), CI: check → e2e → deploy.

## Відкриті питання до замовника

- **Зісковзування −2 кроки** (20.11): без цього з самими помилками ~20% перших стін проходились. Підтвердити або обрати −1/−3.
- Абсолютна гарантія «без відповідей не дійти» неможлива без значно меншого запасу кроків: найкоротший шлях ≈ на 40% коротший за еталонний.
- 2 чи 3 скелелази (зараз 3).
- Чи дозволяти дві руки на одному зачепі (зараз дозволено).
- Хто звіряє 2000 слів: словник SAV (slovnik.juls.savba.sk) і/або носій мови.

## Ідеї й чернетки (ще не в грі)

- **Скіни Пінгвін і Комета** (22.11) — намальовані на полотні «Crux — скіни скелелазів», код уже в репозиторії:
  `draftSkins` у `src/data/skins.ts`, малювання — `fancyCap` (`penguin`, `comet`) і `backExtras` (`tail-penguin`, `sparkles`) у `src/ui/climberArt.ts`.
  Щоб увімкнути: вирішити, чиї вони (Іва/Мартин/Бо) і за скільки зірок, перенести в `skins`, оновити тест і `decisions.md`.
  Комета — власна героїня замість Сейлор Мун (чужих персонажів не малюємо). Ідея: додати Кометі невелику зоряну накидку.
- **Варіанти екрана результату** E–H (небо, листівка, нижня панель, прапорець) — на полотні «Crux — варіанти меню»; в грі обрано F «Листівка».
- **Звук результату**: зараз синтезовані «пік» лічильника, дзенькіт зірок і акорд. Якщо треба ближче до звуку з якоїсь гри — описати його (тембр, ритм), чужі звуки не копіюємо.
